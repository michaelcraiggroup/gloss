# Gloss

> **Reading mode for markdown in VS Code.**

Gloss makes markdown files open as beautifully rendered, read-only
previews — reading is the default, editing is one command away. Syntax
highlighting, Mermaid diagrams, KaTeX math, zen mode.

Free, no telemetry, no data collection.

## Install

From the VS Code marketplace (or `npm run package` in `extension/` for a
local .vsix).

## The bigger picture

Gloss began as this extension plus native Mac and iPhone apps. The native
apps grew into their own product — **Vesta**, the knowledge vault ("keep
the flame") — and moved to their own home. This repo is the extension's,
now and forever free.
